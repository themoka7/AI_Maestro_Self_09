공통코드 그룹은 시스템구분 포함 (예: 0001_TERM_GCD)

여기 등록한 코드는 조회조건·컬럼의 공통코드 칸에서 고를 수 있습니다. 조건(SQL 조각)을 넣으면 common.getCodeByEtcParam 으로 생성됩니다. 팀 공용으로 쓰려면 “설정 JSON 받기” 후 config/ws-config.json 에 커밋하세요.

에이전트 요청문을 Claude Code 에 붙여넣으면 websquare-dev 에이전트가 이어서 다듬습니다.

사내 템플릿 설정

프레임워크마다 다른 부분입니다. 기존 업무 화면(예: 개설강좌 일람표) XML에서 그대로 복사해 넣고 “확인함”을 체크하세요. 이 브라우저에 저장되며, 팀 공유는 “설정 JSON 받기”로 config/ws-config.json 에 반영합니다.
